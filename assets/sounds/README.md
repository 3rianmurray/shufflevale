# Table sound effects

Short MP3s; to change one, replace the file and keep its name:

- `card-flip.mp3`: flipping, drawing and dealing cards
- `shuffle.mp3`: shuffling a deck or stack
- `die-roll.mp3`: rolling one die
- `dice-roll.mp3`: rolling several dice
- `coin-flip.mp3`: flipping a coin

They're quiet while the phone's silent switch is on.
